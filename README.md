# 🔐 Password Strength Checker

## 📌 About the Project

Password Strength Checker is a Python-based project designed to evaluate password strength and help users understand the importance of creating secure passwords.

The project is organized into separate modules for password checking, authentication, database management, and testing.

## 🎯 Project Objectives

- Understand password security concepts.
- Develop a password checking application using Python.
- Organize code using separate modules.
- Practice authentication and database management.
- Test application functionality using Python test files.

## 🛠️ Technologies Used

- Python
- Git
- GitHub
- Python Testing

## 📂 Project Structure

```text
password-strength-checker/
│
├── data/
│
├── src/
│   ├── auth.py
│   ├── database.py
│   ├── main.py
│   └── password_checker.py
│
└── tests/
    ├── test_auth.py
    └── test_password.py
```

## 📁 Folder Description

| File/Folder | Purpose |
|---|---|
| `data/` | Stores project-related data |
| `src/` | Contains application source code |
| `auth.py` | Authentication-related functionality |
| `database.py` | Database-related operations |
| `main.py` | Main application entry point |
| `password_checker.py` | Password checking functionality |
| `tests/` | Contains test files |
| `test_auth.py` | Authentication tests |
| `test_password.py` | Password checking tests |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/gayathri1thanneru/password-strength-checker.git
```

### 2. Navigate to the project

```bash
cd password-strength-checker
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python src/main.py
```

## 🧪 Testing

Run the project tests using:

```bash
python -m unittest discover -s tests
```
